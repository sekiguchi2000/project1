# フリックマスター

スマホ向けの **フリック入力練習アプリ**。パソコンのタイピングソフトのように、遊びながらフリック入力を覚えることをコンセプトにした Web アプリです。

## 特徴

- **本物そっくりのフリックキーボード** — タップ＋上下左右のフリックジェスチャーを検出。押下中はフリック候補のポップアップを表示します。
- **学習ガイド** — 次に打つ文字のキーとフリック方向を矢印でハイライト。指の動きを見ながら覚えられます（💡ボタンでオン/オフ）。
- **4つのゲームモード**
  - 基礎れんしゅう … 行（あ行〜わ行）を選び、ガイドつきで1文字ずつ
  - ランダム文字 … 全文字からランダム出題
  - ことば … 単語を入力する実戦練習
  - タイムアタック … 60秒で高スコアを狙う
- **スコア・コンボ・正確率・入力速度（文字/分）** をリアルタイム計測。結果画面でランク（S〜D）とハイスコアを表示（ハイスコアは端末に保存）。

## 使い方

ビルド不要。静的ファイルなので、そのままブラウザで開くだけで動きます。

```bash
# 例: 簡易サーバーで起動
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く（スマホでの確認推奨）
```

`index.html` を直接開いても動作しますが、スマホ実機やブラウザのデバイスエミュレーションで確認するのがおすすめです。

## 操作

- キーを押して、入力したい文字の方向へ指をスライド（フリック）して離す
- タップ（動かさずに離す）でそのキーの中央の文字（あ・か・さ…）
- PC ではマウスのドラッグでも操作できます（動作確認用）

## 構成

```
index.html              画面構成
css/style.css           スタイル（モバイルファースト）
js/kana.js              フリック配列・かなデータ・単語リスト
js/flick-keyboard.js    キーボード描画とジェスチャー検出
js/game.js              モード・採点・進行ロジック
js/main.js              画面遷移とUIバインド
```
