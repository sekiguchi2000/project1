# フリックぼうけん 🟢⚔️

スマホ向けの **フリック入力練習アプリ**。タイピングソフトのように、**遊びながらフリック入力を覚える**ことをコンセプトにした、かわいいキャラ系の Web アプリ（PWA）です。

マスコット「モモ」と一緒に、モンスターを倒しながらフリック入力をマスターしよう！

## あそびかた

キーを押して、入力したい文字の方向へ指をスライド（フリック）して離します。
**「小゛゜」キー**で、直前の文字を **濁点 → 半濁点 → 小書き**（か→が、は→ば→ぱ、つ→っ）に変換できます。本物のスマホのフリック入力と同じ操作です。

PC ではマウスのドラッグでも操作できます（動作確認用）。

## モード

- **⚔️ ぼうけんモード（目玉）** … 言葉を打ってモンスターにダメージ。敵は時間ゲージがたまると攻撃してくる。倒すと **XP → レベルアップ**。全4ステージ＋各ボス。レベルや進行は端末に保存され、強くなって再挑戦できます。
- **きそれんしゅう** … 行（あ行〜わ行）を選び、ガイドつきで1文字ずつ
- **ランダム** … 全文字からランダム出題で腕だめし
- **ことば** … 単語を入力する実戦練習
- **タイムアタック** … 60秒で高スコアを狙う

スコア・コンボ・正確率・入力速度（文字/分）をリアルタイム計測。学習ガイド（💡）で次に打つキー・方向・「小゛゜」回数をハイライトします。効果音は WebAudio で合成（音声ファイル不要）、🔊ボタンでミュート可。

## 動かし方

ビルド不要の静的サイトです。

```bash
python3 -m http.server 8000   # http://localhost:8000 をスマホ/エミュで開く
```

- **1ファイル版**: `standalone.html` 単体でも動きます（保存して開くだけ）。
- **PWA**: サーバー（HTTPS）経由だと Service Worker が有効になり、**オフラインでも動作**＆ホーム画面に追加できます。

## 構成

```
index.html              画面構成（ホーム/マップ/プレイ/バトル/結果）
manifest.json           PWA 設定
sw.js                   Service Worker（オフラインキャッシュ）
css/style.css           かわいいテーマのスタイル
js/kana.js              フリック配列・濁点/小書き変換・入力判定・単語プール
js/sound.js             WebAudio 効果音
js/storage.js           進行データ保存（レベル・XP・コイン・ベスト）
js/flick-keyboard.js    キーボード描画とジェスチャー検出
js/game.js              アーケード各モード
js/rpg.js               ぼうけんモード（バトル・ステージ）
js/main.js              画面遷移・UI・マスコット
icons/                  アプリアイコン（gen-icons.js で生成）
gen-icons.js            アイコン生成スクリプト（node のみ・ライブラリ不要）
standalone.html         全部入りの1ファイル版（自動生成物）
```

## Google Play へのリリース（PWA → Android アプリ）

このアプリは PWA なので、**TWA（Trusted Web Activity）** として Android アプリに包めます。

1. GitHub Pages 等で HTTPS 公開する（例: `https://sekiguchi2000.github.io/project1/`）
2. **[PWABuilder](https://www.pwabuilder.com/)** に URL を入力 → Android パッケージ（.aab）を生成（アイコン各サイズも自動生成）
3. **Google Play Developer 登録**（一度だけ $25）
4. 生成した .aab をアップロードし、ストア情報・プライバシーポリシー・コンテンツレーティングを設定
5. ※ 2023/11 以降の個人アカウントは、本番公開前に「**12人以上 × 14日間**のクローズドテスト」が必要

iOS は TWA 非対応のため、Capacitor 等で包む別ルート＋Apple Developer（年99ドル）が必要です。
